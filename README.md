# Student REST API

## Project Overview
This project is a RESTful API developed using Java and Spring Boot to manage student information.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- REST API

## Features
- Add student records
- Retrieve student information
- Update student records
- Input validation and API responses

## Learning Goals
- Understand REST API development
- Practice CRUD operations
- Learn database integration using PostgreSQL
- Improve Java and Spring Boot skills
